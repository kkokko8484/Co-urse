# Co:urse (플러터 프로토타입)

첨부해주신 UI 시안(①상황에 맞는 코스 추천받기, ②친구들과 함께 코스 만들기)과
스플래시 화면을 그대로 반영한 Flutter 앱입니다.

## 포함된 화면 흐름

**앱 실행**
- 스플래시 화면 (`Co:urse` 오렌지 배경) → 홈 화면

**홈 화면**
- `친구들과 함께 코스 만들기` → 친구 초대 → 취향 선택(3단계: 상황 / 취향 / 피하고 싶은 요소)
  → 분석 중 → 추천 코스 → 코스 상세 → 재추천(아쉬우셨나요) → 일정 저장
- `상황에 맞는 코스 추천받기` → 취향 선택(4단계: 누구와 / 상황 / 취향 / 피하고 싶은 요소)
  → 분석 중 → 추천 코스 → 코스 상세 → 재추천(아쉬우셨나요) → 일정 저장

## 폴더 구조

```
lib/
  main.dart                 앱 진입점 (스플래시 화면부터 시작)
  app_colors.dart           색상 팔레트
  models/models.dart        데이터 모델 (CourseFlowData, CourseStop 등)
  data/dummy_data.dart      화면에 쓰이는 목업(더미) 추천 데이터
  widgets/                  공용 위젯 (버튼, 칩, 스텝 헤더 등)
  screens/                  각 화면 (스플래시, 홈, 취향 선택 4종, 분석중,
                              추천 코스, 코스 상세, 일정 저장)
```

## 실행 방법

1. [Flutter SDK](https://docs.flutter.dev/get-started/install)를 설치합니다. (3.x 이상 권장)
2. 이 프로젝트 폴더로 이동한 뒤 의존성을 설치합니다.
   ```bash
   flutter pub get
   ```
3. 에뮬레이터/기기를 연결한 뒤 실행합니다.
   ```bash
   flutter run
   ```

## 참고 사항

- 실제 사진/일러스트 대신 아이콘 + 색상 블록으로 이미지 영역을 표현했습니다.
  나중에 실제 이미지 에셋을 추가하시려면 `assets/` 폴더를 만들고
  `pubspec.yaml`의 `flutter:` 항목에 경로를 등록한 뒤,
  각 화면의 `Container`/`Icon` 부분을 `Image.asset(...)`으로 교체하면 됩니다.
- 추천 코스 데이터는 `lib/data/dummy_data.dart`에 하드코딩되어 있습니다.
  이후 AI/백엔드 연동 시 이 부분을 실제 API 호출 결과로 교체하시면 됩니다.
- 캘린더는 별도 패키지 없이 직접 구현한 간단한 달력 위젯입니다.
